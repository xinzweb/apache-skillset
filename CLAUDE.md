# apache-skillset

Unofficial community Claude Code plugin: skills for Apache Cloudberry (Incubating) contributors.

- Layout: `skills/<name>/SKILL.md`, shared facts in `references/`, manifest in `.claude-plugin/`.
- Validate before any PR: `claude plugin validate .`
- Keep this repo public-safe: no secrets, no personal data, no internal-company material, no ASF logos.
- Do not imply ASF endorsement; use official names (Apache Cloudberry (Incubating)).
- Changes go through a feature branch and PR; no direct pushes to `main`.
- Task tracking is in a private hub repo, not here.
